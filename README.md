## Why SuperBots?

**GrokBot** and **Muse by Meta** put autonomous AI agents behind closed clouds, fixed models, and vendor-hosted virtual machines. **SuperBots** gives you the same always-on digital coworkers—running directly on your own computer, using whatever models and tools you choose.

| | **SuperBots** | **GrokBot (xAI)** | **Muse by Meta** |
| :--- | :--- | :--- | :--- |
| **Price** | **Free** (BYOK or \$0 local models) | Proprietary / Paid | Proprietary / Platform-controlled |
| **Privacy & Control** | Runs on **your machine**; plain files you own | xAI cloud computers | Meta Secure VM |

| **Spend Limits** | Hard **weekly USD budget caps** per bot | Platform limits | Platform limits |

## What SuperBots Can Do

- **Always-On Digital Teammates** — Create specialized bots (research, outbound sales, engineering, ops, inbox triage) that keep working across sessions and background schedules.
- **Chat or Full Terminal Mode** — Talk to your bots in a clean chat interface, or let them work in a real terminal using `Claude Code`, `Codex`, `Droid`, `Antigravity`, `Cursor`, `Warp`, `OpenCode`, or `Grok Build`.
- **Safe Code Isolation** — Assign any bot its own Git worktree so it can write and test code without messing up your active branch.
- **Persistent Identity & Memory** — Every bot has editable plain-Markdown `agent.md`, `SOUL.md`, and `MEMORY.md` files, plus semantic memory search so it remembers your preferences, past runs, and context across fresh sessions.
- **Human-in-the-Loop Approvals** — Keep bots on a tight leash with `Sensitive`, `Always`, or `Never` approval modes and custom *"Always allow"* rules. Sensitive actions (sending messages, writing to integrations, shell commands, or changing `SOUL.md`) pause until you approve.
- **Control From Anywhere** — Chat with your bots, review work, and approve or deny actions from the **Desktop app**, the **Mobile Companion**, or **Telegram**.
- **Bot-to-Bot Handoffs** — Bots can delegate tasks to other specialist bots on your team and track background runs in one view.
- **Scheduled Routines** — Run bots automatically on a cron schedule with pass/fail checks and instant Telegram or Inbox notifications.
- **Weekly Budget Caps** — Set a weekly dollar cap per bot so runaway loops stop automatically before blowing your API bill.
- **1,000+ Integrations** — Connect GitHub, Gmail, Slack, Notion, Stripe, Shopify, Postgres, Tavily, Composio, and more—your credentials stay encrypted and are never exposed in prompts or logs.

## Get Started

### 1. Download

Grab the latest release from **[GitHub Releases](https://github.com/SuperConsoleAI/superconsole/releases)** and open **SuperConsole**.

### 2. Connect Your AI Key (or Local Model)

Go to **Settings → Models** and add an API key from **Anthropic**, **OpenAI**, **Google Gemini**, **OpenRouter**, or point to a **local model**. You only pay your provider directly (or \$0 locally).

### 3. Create Your First Bot

1. Open the **SuperBots** tab and click **`+` (New bot)**.
2. Give your bot a name and job description (e.g., *"Triage GitHub issues and summarize daily PRs"*).
3. Pick **Chat** or a **CLI runner**, choose an **Approval Mode**, and optionally set a **Weekly Budget** or **Git Worktree**.
4. Start chatting—or put it on a schedule and manage approvals right from your phone or Telegram.
